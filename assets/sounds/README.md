# 소리 파일 (선택)

이 폴더에 아래 이름의 mp3를 넣으면 기본 효과음 대신 그 파일을 씁니다.
없으면 브라우저가 직접 만드는 기본 효과음이 나옵니다. 하나씩 바꿔도 됩니다.

| 파일 | 언제 |
|---|---|
| `bgm.mp3` | 배경음악 (반복 재생, 기본 효과음 없음) |
| `tap.mp3` | 버튼 누를 때, 먹이 고를 때 |
| `nope.mp3` | 안 되는 행동 (자는 중, 배부름 등) |
| `chirp.mp3` | 게코를 톡 건드렸을 때 |
| `eat.mp3` | 먹이를 먹을 때 |
| `start.mp3` | 벌레 잡기 시작 |
| `catch.mp3` | 벌레를 잡았을 때 |
| `yay.mp3` | 벌레 잡기 끝 (한 마리 이상 잡음) |
| `pick.mp3` | 응가를 집게로 집을 때 |
| `clean.mp3` | 사육장 청소 끝 (반짝) |
| `water.mp3` | 물 갈아줄 때 (졸졸) |
| `sleep.mp3` | 재울 때 |
| `wake.mp3` | 깨울 때 / 스스로 깼을 때 |
| `grow.mp3` | 다음 단계로 자랐을 때 |
| `poop.mp3` | 응가했을 때 |
| `lamp.mp3` | 히팅램프 켜고 끌 때 (딸깍) |

효과음은 1~2초 이내로 짧게, 배경음악은 잔잔한 곡으로 고르세요.
무료 효과음은 pixabay.com/sound-effects 등에서 구할 수 있습니다. (라이선스 확인)
